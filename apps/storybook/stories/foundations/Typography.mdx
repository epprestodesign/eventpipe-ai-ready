# Typography

The EventPipe type scale is built on **Inter**, a highly legible variable font optimized for UI. All size and weight values are expressed as semantic tokens.

| `h6` | `--ep-semantic-typography-h6-font-size` | `--ep-semantic-typography-h6-font-weight` |

## Font family

```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

Inter is loaded via the application's font configuration. The design system does not bundle the font — ensure Inter is available in your app before importing EP tokens.

---

## Usage guidance

| Use case | Recommended variant |
|---|---|
| Page titles | `h4` or `h5` |
| Section headings | `h6` or `subtitle1` |
| Card titles | `subtitle1` or `subtitle2` |
| Body copy | `body1` (16px) |
| Secondary text, descriptions | `body2` (14px) |
| Labels, captions, metadata | `caption` (12px) |
| Category tags, overlines | `overline` (12px, uppercase) |
| Button labels | `button` (14px, medium) |
