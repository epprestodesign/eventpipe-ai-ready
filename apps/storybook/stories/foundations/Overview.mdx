# Foundations

Foundations are the visual and structural decisions that underpin every component in the EventPipe Design System. They are expressed as tokens — named values that travel through three layers from raw values to component-level defaults.

## How foundations become tokens

Foundations are not abstract guidelines — they are compiled into CSS custom properties and distributed via `@eventpipe/tokens`. Every component reads from the component-layer (`--ep-component-*`) which references semantic decisions (`--ep-semantic-*`) which ultimately resolve primitive values (`--ep-primitive-*`).

```
Design decision:  "The primary brand color is #0057FF"
         ↓
primitive.color.blue.600    →   #0057FF
         ↓
semantic.color.brand.primary    →   {primitive.color.blue.600}
         ↓
component.button.contained.primary.background   →   {semantic.color.brand.primary}
         ↓
CSS output:  --ep-component-button-contained-primary-background: #0057FF
```

Changing the primitive value propagates automatically to every component that references it.
