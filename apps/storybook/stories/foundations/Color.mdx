# Color

The EventPipe color system is built on semantic tokens — you reference intent (`brand.primary`, `status.error`) rather than raw hex values. All colors are available as CSS custom properties on `:root`.

## Usage rules

- **Only use semantic tokens** in component and application code. Never reference primitive tokens directly.
- **Component code** must only use `--ep-component-*` vars via the TOKEN helper map. Never `--ep-semantic-*` directly in component CSS.
- **Application styles** may reference `--ep-semantic-*` vars for custom layout areas adjacent to components.
- **Never hardcode hex values** — all color decisions must go through the token system.
