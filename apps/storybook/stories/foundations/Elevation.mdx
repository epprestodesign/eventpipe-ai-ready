# Elevation

Elevation communicates the z-axis position of a surface. In EventPipe, elevation is expressed as multi-layer `box-shadow` tokens and maps to MUI's elevation scale.

## Rules

- **Never override z-index with tokens.** Z-index values are structural constants owned by MUI's theme layer. EventPipe does not define `z-index` tokens.
- **MUI z-index stack:**

| Layer | z-index | Components |
|---|---|---|
| App Bar | 1100 | AppBar, TopNav |
| Drawer | 1200 | Drawer |
| Modal / Menu | 1300 | Dialog, Menu, Popover, Backdrop |
| Snackbar | 1400 | Snackbar |
| Tooltip | 1500 | Tooltip |

- Shadow tokens are defined as `$type: shadow` in token JSON and compile to `box-shadow` CSS values.
- All portal surfaces (Dialog, Drawer, Popover, Menu) receive their shadow via `PaperProps.sx` using `PAPER_SX` — not via `styled()` ancestor selectors, which cannot reach portal content.
