# Border & Radius

Border colors and corner radius values are defined as component-layer tokens. There is no shared global radius scale — each component specifies its own radius appropriate to its shape and visual weight.

## Rules

- **No shared global radius token** — each component defines its own radius as a component token.
- Radius values follow the component's visual weight: modals and large surfaces use larger radii (12px); small interactive elements use smaller radii (4px).
- `0px` radius is reserved for full-edge panels like Drawer, where the panel meets the viewport edge.
- Focus ring radius is always **structural** (2px rounding) and never driven by design tokens — it is hardcoded as a convention across all interactive controls.
