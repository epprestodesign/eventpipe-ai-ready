## Package structure

```
@eventpipe/tokens   — Compiled CSS custom properties (--ep-component-*, --ep-semantic-*, --ep-primitive-*)
@eventpipe/ui       — React components built on MUI 5 + EP token layer
```

## Quick install

```bash
pnpm add @eventpipe/ui @eventpipe/tokens
```

```tsx
// In your app root
import '@eventpipe/tokens/css';

// In your component
import { Button } from '@eventpipe/ui';

<Button variant="contained">Create event</Button>
```
