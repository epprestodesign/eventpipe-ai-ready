# Product Screens

These screens are full-page product compositions built entirely from the EventPipe design system.
They validate that components work together in realistic layouts and serve as living product references.

Each screen supports four states via the `pageState` prop: **default**, **loading**, **empty**, and **error**.

---

## Dashboard

KPI cards, chart tabs, activity feed, and a sortable paginated event DataGrid.
Exercises: Card, DataGrid, Tabs, LinearProgress, Badge, Chip, List, Skeleton, Alert,
Breadcrumbs, DatePicker, Tooltip, Link, Pagination, Icon.

## Data Table

Attendee management with filtering, row selection, bulk actions, inline editing (Drawer),
and delete confirmation (Dialog).
Exercises: DataGrid, TextField, Select, DatePicker, Switch, Chip, Avatar, Drawer, Dialog,
Checkbox, Divider, Alert, Breadcrumbs, Pagination.

## Settings

Multi-step event creation wizard with form controls, staff assignment, review summary,
and unsaved-changes guard.
Exercises: Stepper, TextField, Select, Autocomplete, Checkbox, Switch, RadioGroup, DatePicker,
TransferList, Popover, Dialog, LinearProgress, Chip, List, Divider, Alert, Breadcrumbs.
