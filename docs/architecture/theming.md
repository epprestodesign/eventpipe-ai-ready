# Theming

## MUI Integration
`@eventpipe/theme` exports `EventPipeThemeProvider`, which wraps MUI's `ThemeProvider`
with EventPipe token values mapped to MUI theme shape.

Token → MUI mapping is generated by Style Dictionary's `muiTheme` output platform.
See `docs/specs/tokens/04-style-dictionary.md`.

## Theme Modes
| Mode  | Mechanism                                |
|-------|------------------------------------------|
| Light | Default CSS custom property values       |
| Dark  | `.dark` class override OR `prefers-color-scheme: dark` |

## Token → MUI Theme Mapping
| MUI path                 | Token source                        |
|--------------------------|-------------------------------------|
| `palette.*`              | `ep.semantic.color.*`               |
| `spacing(n)`             | `ep.semantic.spacing.*`             |
| `typography.*`           | `ep.semantic.typography.*`          |
| `shape.borderRadius`     | `ep.primitive.border.radius.*`      |
| `breakpoints.values.*`   | `ep.primitive.breakpoint.*`         |

## xs Breakpoint Override
MUI default `xs: 0` overridden to `444px` per Decision #001.

```ts
createTheme({
  breakpoints: {
    values: { xs: 444, sm: 600, md: 900, lg: 1200, xl: 1536 }
  }
})
```

## Usage
```tsx
import { EventPipeThemeProvider } from '@eventpipe/theme';

<EventPipeThemeProvider mode="light">
  <App />
</EventPipeThemeProvider>
```
